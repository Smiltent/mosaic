
This isn't any official pack, this is just to explain how the pack system even works in the first place.  
In `block-def.json` & `smiley-def.json`, you will define each id for each block, assosiated with which image.  
Block BG and FG ID's are different systems, if you define a FG block on ID 1, it will assosiate the BG block on top of it.  

You can either go with the default EE block placement format in `packs/ee-original/` and use the definitions there or use your own format, and define it each one yourself.  

Theoretically, you can define each smiley, block, etc with just a single block and make the entire game a mess.
